# Presenting session 4

The runbook is **[`PRESENTING.html`](PRESENTING.html)** — open it in a browser.

It is one offline page: the five commands to run live (none takes longer than two seconds), the
measured numbers to read off the slides instead of reproducing, and what to do when Docker,
a port, or the images are not where you expect. Every command on it was run before it was
written.

Kept as HTML rather than Markdown because it carries the charts and the copy-to-clipboard
buttons a presenter actually uses. This file exists so the link is findable from GitHub, where
`.html` renders as source.
